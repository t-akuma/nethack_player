# 序盤〜中盤の攻略戦略

## キャラクター選択

**ユーザーに確認してから決める。** 好みが無いと言われた場合の推奨:

- **Valkyrie**(推奨): HPと近接性能が高く、初期装備だけで序盤を戦い抜ける。アイテム識別に失敗しても事故りにくい。人間なら中立、ドワーフなら秩序。
- **Samurai**: バランス型。初期に弓矢を持つので floating eye などを遠距離処理できるのが大きい。
- **Barbarian**: 毒耐性を最初から持つのが強い。

避けたほうが無難:

- **Wizard / Priest**: 呪文・魔力・識別の管理が複雑で、判断ミスが積み重なりやすい。
- **Tourist / Archeologist**: 初期装備が貧弱で、序盤の事故率が高い。
- **Healer**: 戦闘力が低く、逃げ回る立ち回りが必要になる。

## ダンジョンの構造(序盤の地図)

| 場所 | 深さの目安 | 内容 |
|---|---|---|
| Gnomish Mines 入口 | **Dlvl 2〜4** の下り階段(通常の階段とは別にもう一つある) | 分岐ダンジョン。gnome/dwarf が多い |
| Minetown | Mines に入って数階下 | 店・寺院・祭壇がある。識別と買い物の拠点 |
| Mines' End | Mines の最下層 | 宝石が大量にあるが、たどり着くのは中盤以降 |
| Oracle | **Dlvl 5〜9** | 有料でヒントをくれる。目印になる |
| Sokoban 入口 | **Oracle の1つ下の階にある「上り階段」** | 倉庫番パズル。4階層を上っていく |
| Sokoban 最上階の報酬 | — | **bag of holding または amulet of reflection**(どちらかがランダム) |

覚え方: **Mines は浅い(2-4)、Sokoban は Oracle の真下から上に登る。**

## 序盤(Dlvl 1-5)の方針

0. **レベルアップしたら必ず `ext enhance`。** 上げられる武器・呪文スキルがあれば上げる。
   放置しても警告は出ないので、忘れたまま深層へ行きがち。`Xp:` の数字が増えたら確認する。
1. **各階を一通り探索してから降りる。** 金・食料・アイテムを取りこぼさない。行き止まりでは `10s` で10回まとめてサーチして隠し通路を探す(1回ずつ送るより速い)。
2. **ペットを大事にする。** 初期ペット(子犬/子猫)は序盤の主戦力であり、店で盗ませる・アイテムの呪い判定をさせるなどの用途もある。階段ではペットが隣にいる状態で降りること(離れていると置き去りになる)。
3. **食料管理。** `Hungry` が出たら早めに食べる。死体は倒した直後に食べる(時間が経つと腐って食中毒になる)。ただしコカトリスなど食べてはいけない死体がある(`references/dangers.md`)。
4. **装備は慎重に。** 拾った鎧・武器も呪われている可能性がある。`references/identification.md` の手順で確認してから装備する。
5. **無理に潜らない。** 明らかに手に負えない敵が出る階では、退いて別ルートを探すか、上の階で経験値を稼ぐ。

## Minetown を目指す価値

Dlvl 2-4 の Mines 分岐に入って Minetown まで行くと、以下がまとめて手に入る:

- **祭壇**: 未識別アイテムの呪い判定ができる(識別戦略の要)
- **店**: 値段による識別(price-ID)ができる
- **寺院**: 有料で呪い解除ができる

序盤の装備が整っていれば、深く潜るより先に Minetown を目指すほうが安定する。

### 分岐を見失わないために

Mines の入口は「通常の下り階段とは別に、もう一つ下り階段がある階」にある。
どちらを降りたか分からなくなりやすいので、**ゲーム内の注記機能を使う**:

- `ext overview`(`^O`): 訪れた階の一覧。分岐階段・祭壇・店は自動で注記される。
  「Mines の入口はどこだったか」はまずこれを見る
- `ext annotate`(`M-A`): 今いる階に自分でメモを付ける。例「Mines 入口・こちらが分岐」

外部ログと違ってセーブファイルに残るので、セッションをまたいでも消えない。

## Sokoban の注意

パズルなので、**岩(boulder)を押す方向を間違えると詰む**。詰んだ場合、そのフロアはクリア不能になる(掘って抜けることもできない — Sokoban の壁と1階の床は掘れない)。

- 押す前に、その岩を穴まで運べる経路があるか確認する。
- 岩を押して壁際や角に固定してしまうと復帰できない。
- 焦らず1手ずつ検討する。ここは特に「まとめてキーを送る」をやってはいけない場所。
- **Sokoban では `_`(travel)を使わない。** 経路を勝手に選ぶため、意図しない方向から
  岩を押してしまう。1マスずつ `hjkl` で動かし、岩に触れる手は毎回画面を読んでから送る。
- 岩を押さない方法は「岩のマスに向かって歩かない」以外に無い。プレフィックスでは避けられないので、
  移動キーを送る前に進行方向のマスが `` ` ``(岩)でないか毎回確かめる。
- 盤面の把握には `ext terrain` が効く。モンスターやアイテムを消した状態で
  岩と穴の配置だけを見られる。

## 判断に迷ったときの優先順位

1. **生存**(HP、状態異常の解消)
2. **安全確保**(戦うか逃げるか、位置取り)
3. **装備と識別の改善**
4. **探索と進行**

上位が脅かされているときに下位を追わない。「あのアイテムを取りに行きたい」が「HPが残り4」に勝ることはない。
