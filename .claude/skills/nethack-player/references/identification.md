# アイテム識別戦略

NetHack のアイテムはゲームごとに見た目(色・材質名など)とアイテム種別の対応がランダム化される。同じ「青い薬」でも周回ごとに中身が違う。だから**推測でいきなり使わない**。

## 安全な識別手順(優先度順)

1. **店で値踏みする**: shopkeeperに price-ID してもらう(店に入って `#chat` するか、店内でアイテムを持って店主に尋ねる、または単純に売却査定額を見る)。値段帯からある程度種別を絞れる。
2. **祭壇で真贋・アライメント確認**: `#offer` 前にアイテムを祭壇の上でドロップすると、祝福/呪い状態(blessed/uncursed/cursed)が光で分かる。中身の種類そのものは分からないが、安全に使えるかの判断材料になる。
3. **巻物**: 未識別の巻物は、状況が安全なとき(敵がいない、ペットが近くにいる)に読んでみて効果を観察するのが基本。ただし "scroll of fire" や "scroll of punishment" のような危険な効果もあるため、HPに余裕がある時に限定する。
4. **ポーション**: 
   - 投げて割ってみる(自分に影響しない効果を安全に判別できる)
   - 未識別のまま飲むのはHPに余裕がある時のみ
   - **危険な例外**: `potion of acid`, `potion of paralysis` など。全回復してから試す運用にする。
5. **指輪・アミュレット**: 呪われていると外せなくなるものがある。祭壇でBUC(blessed/uncursed/cursed)を確認してから装備するのが安全。
6. **刻印識別(engrave-ID)**: `E` で床に刻む際、巻物やダガーなどアイテムによって刻む文字の見た目やメッセージが変わることがあり、種別のヒントになる場合がある(すべてのアイテムに使えるわけではない)。

## 危険なので基本使わない/後回しにする

- 未識別のワンド(杖)を自分に向けて振る
- 未識別の巻物を、敵に囲まれている最中に読む
- 未識別の指輪をいきなり装備する(外せなくなるリスク)

## 識別状態を画面から確認するコマンド

推測の前に、ゲームが既に知っていることを引き出す。どれもターンを消費しない。

| コマンド | 分かること |
|---|---|
| `\` (`#known`) | **この周回で識別済みのアイテム種別の一覧。** 「もう分かっている」ものを試す無駄が消える |
| `` ` `` | 1クラス(薬だけ、巻物だけ)に絞った識別済み一覧 |
| `IB` / `IU` / `IC` | 持ち物のうち **祝福済み / 無呪い / 呪い** と判明しているものの一覧 |
| `IX` | **BUC 不明のものの一覧。** 祭壇に持ち込むべきものがこれで分かる |
| `*` | 装備中のものの確認(`)` 武器 / `[` 防具 / `=` 指輪 / `"` アミュレット に分解も可) |

**未識別のものを使う前に、まず `\` と `IX` を見る。**
祭壇に着いたら `IX` で BUC 不明のものを全部拾い出してからまとめてドロップする。

## 識別済み情報の記録

識別結果はゲーム内に残す。`C`(または `ext name`)でアイテム種別に名前を付けておくと、
以後の持ち物表示にその名前が出るので、セッションをまたいでも判断材料が消えない。

- 種別に名前を付ける: 「青いポーション」全部に "healing?" と付ける
- 個体に名前を付ける: この1本だけに "altar-checked" と付ける

確定した識別は `\`(known)に自動で載るので、名前付けは**「まだ確定していないが
そう推定している」情報**を残すために使うのが効く。

推定の根拠(値段、祭壇での反応、投げた結果)は
`scripts/cmux_nethack.sh note` にも1行残しておく。名前だけでは後から根拠が辿れない。
