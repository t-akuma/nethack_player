# 危険なモンスター・状況判断

## モンスタークラス文字(要点)

NetHack ではモンスターは種別ごとに決まった文字で表示される(色は職業/個体で変わるが**文字は種別で固定**)。序盤で見かける主なもの:

| 文字 | クラス | 備考 |
|---|---|---|
| `a` | 蟻・昆虫 | 序盤の soldier ant は非常に速く強い。要注意 |
| `b` | ブロブ | acid blob 含む。**殴ると武器が腐食する** |
| `c` | コカトリス系 | **石化。最重要警戒対象**(下記) |
| `d` | 犬系 | 群れで来る。ペットもここ |
| `e` | 眼・球体 | **floating eye は近接厳禁**(下記) |
| `f` | 猫系 | ペットもここ |
| `F` | **菌・カビ** | lichen(粘着)、各色 mold(接触ダメージ)、violet fungus。**動かないので避けて通れる** |
| `j` | ゼリー | 接触で受動ダメージのものがある |
| `m` | **ミミック** | 物やドアに化けている。`]` で表示されることも |
| `P` | プディング/ウーズ | 鉄武器で殴ると分裂するものがある |
| `:` | トカゲ | newt/lizard。lizard corpse は石化解除に使える貴重品 |
| `@` | 人間・エルフ | 店主(shopkeeper)もここ。**店主に手を出すと即死級** |

わからない文字が出たら、ゲーム内の `;`(farlook)や `/`(whatis)で正体を確認してから行動する。推測しない。

## 絶対にやってはいけないこと

1. **floating eye (`e`) を近接攻撃しない。** 麻痺して身動きが取れず、他のモンスターに袋叩きにされて死ぬ。倒すなら投擲・杖・呪文などの遠距離手段のみ。安全に倒せた場合、死体を食べるとテレパシーが得られるので価値は高い。

   具体的な手順: `Q` で矢やダガーを quiver に入れ、`f` で撃つ(`t` で個別に投げてもよい)。
   Samurai や Ranger は初期装備の弓矢でこれができる。遠距離手段が無いなら**戦わずに避ける**。
   `e` に隣接した状態で移動キーを押すと攻撃になってしまうので、離れるときは
   `m` プレフィックス付きで動くか、`_`(travel)で別の場所へ移動する。
2. **コカトリス (`c`) およびその死体を素手で触らない。** 石化して即ゲームオーバー。死体を扱うなら必ず手袋を装着してから。
3. **店主 (`@`) を攻撃しない。** 序盤の店主は圧倒的に強く、まず勝てない。店内で盗みもしない。
4. **酸を持つ相手 (`b` の acid blob 等) を良い武器で殴らない。** 武器が腐食する。素手か使い捨ての武器で。

## 低HP時の判断フロー

HP が最大値の 1/3 を切ったら、以下の順に検討する:

1. **離脱**: 階段や既知の安全地帯へ退く。通路に引き込めば複数の敵と同時に戦わずに済む。
2. **回復手段**: 識別済みの回復ポーション、食料(空腹による能力低下がある場合)。
3. **緊急脱出**: テレポート系のアイテムがあれば使う。
4. **祈る (`ext pray`)**: 上記が全部だめな場合の最終手段。

### 祈りのルール

祈りは強力(HP全快、food poisoning や石化の解除など)だが、**連発すると神が怒り、罰を受ける**。

- ゲーム開始直後は祈れる状態にあることが多いが、一度祈ると次に安全に祈れるまで**およそ 500〜1000 ターン**の間隔が必要になる。
- 祈っていいのは「major trouble」がある時だけ:瀕死(HP が最大の 1/7 以下または 6 以下)、食中毒、病気、石化進行中、餓死寸前(`Weak` 以上の空腹)、罠に閉じ込められた、など。
- **困っていないのに祈らない。** trouble が無い状態で祈ると、運が良くても何も起きず、悪いと罰を受ける。
- 前回祈ったターン数は `scripts/cmux_nethack.sh note` に記録しておくこと。
  ゲーム内の `#chronicle` や `#overview` には残らないので、外部ログでしか追えない。

### 祈るときの送り方

```bash
scripts/cmux_nethack.sh ext pray          # '#pray' + Enter
scripts/cmux_nethack.sh read              # "Are you sure you want to pray? [yn] (n)"
scripts/cmux_nethack.sh keys "y"          # Confirm 設定時は answer "yes"
```

このスキルの `.nethackrc` は `paranoid_confirmation` に `pray` と `Confirm` を入れているので、
**確認プロンプトが `[yes/no]` 形式なら `y` では通らない。**画面の表記を見て
`answer "yes"` を使う。逆に言えば、キーが1つ暴発しても祈りが実行されることはない。

**`M-p` は使わない。** meta キーは Escape との合成に頼るため、
`Escape` でプロンプトを閉じた直後の文字が `#pray` に化ける事故の温床になる
(だから `.nethackrc` で `altmeta` を無効にしてある)。

## 状態異常への対応

| 状態 | 影響 | 対処 |
|---|---|---|
| `Conf`(混乱) | 移動方向がランダムになる | 安全な場所で `s` を連打して自然回復を待つ |
| `Stun`(朦朧) | 同上、より強い | 同上 |
| `Blind`(盲目) | 視界喪失 | 既知の地形なら移動可。新規の戦闘・探索は避ける。**顔にクリームパイや毒液を浴びた場合は `ext wipe` で拭えば即座に治る**(呪文や病気由来の盲目には効かない) |
| `Hallu`(幻覚) | モンスターの見た目がでたらめになる | **文字での判断が不可能になる。** 戦闘を避け、回復を待つ |
| `Ill`(病気) | 放置すると死亡 | 治癒手段が無ければ祈る(major trouble に該当) |
| `Weak` / `Fainting`(空腹) | 能力低下、やがて死亡 | すぐ食べる。食料が無ければ祈る |
| 石化進行中 | 数ターン後に死亡 | lizard corpse か酸ポーションを摂取、または祈る。最優先 |

**`Hallu` の間はこのファイルのモンスター文字表が役に立たない。**
表示される文字も `;`(farlook)が返す名前もでたらめになるので、**確認手段が両方とも死ぬ。**
幻覚中は新しい敵と戦わず、安全な場所で回復を待つのが最も安全。

## 死んだら

死亡は NetHack の通常の一部。ログに何が起きたか記録し、ユーザーにリスタートするか確認する。勝手に新しいゲームを始めない。
