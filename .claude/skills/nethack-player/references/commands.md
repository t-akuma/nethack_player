# NetHack 5.0.0 キー操作・画面の読み方

対象は **NetHack 5.0.0**(`nethack --version` で確認できる)。3.6 から変わった箇所があるので、
うろ覚えの 3.6 の知識で送らないこと。変更点は「3.6 からの変更」節にまとめてある。

一次情報: `doc/Guidebook.txt` の 4章。ゲーム内では `?`(ヘルプ)、`&`(そのキーの説明)、
`#?`(拡張コマンド一覧)で引ける。**思い出せないときは推測せず `&` か `#?` で引く。**

## 画面レイアウト(80x24, statuslines:2)

実際の起動直後の画面(このスキルの `assets/nethackrc` 使用時):

```
 1|Velkommen Claude, welcome to NetHack!  You are a neutral human Valkyrie.
 2|--More--
 3|
 6|   --------
 7|   |......|
 8|   |.$....|
 9|   |.....:|
10|   |Z.....|
11|   |..{@f..
12|   -----.--
23|Claude the Stripling           St:17 Dx:14 Co:18 In:7 Wi:8 Ch:11 Neutral
24|Dlvl:1 $:0 HP:16(16) Pw:2(2) AC:6 Xp:1/0 T:1
```

- **1行目(と溢れた場合は2行目)**: メッセージ行
- **2〜22行目**: マップ
- **23行目**: 名前・称号 / `St: Dx: Co: In: Wi: Ch:` / 属性(Lawful/Neutral/Chaotic)
- **24行目**: `Dlvl:` `$:` `HP:x(y)` `Pw:x(y)` `AC:n` `Xp:n/exp` `T:n`、
  そのあとに状態異常(`Hungry` `Weak` `Burdened` `Conf` `Stun` `Blind` `Hallu` `Ill` `FoodPois` など)が続く

`AC` は小さいほど良い。**HP は毎回まず見る。**

### `--More--` はどこに出るか

**メッセージの直後**に出る。画面右下ではない。1行目のメッセージが長ければ
上の例のように**2行目の行頭**に出る。「右下に出る」と思って探すと見落とす。

Space または Enter で進む。Escape を送ると残りのメッセージを飛ばして進む
(読み飛ばしたくないときは Space を使う)。

## 画面が「コマンド待ち」でない4つの状態

キーを送る前に、画面が下のどれかでないか必ず確認する。どれかに当たっているのに
移動キーを送ると、その文字がプロンプトへの回答として消費されて全部ズレる。

| 状態 | 画面の見た目 | 抜け方 |
|---|---|---|
| メッセージ継続 | `--More--` | Space(飛ばすなら Escape) |
| yes/no プロンプト | `Really attack? [yn] (n)` / `Are you sure you want to pray? [yn] (n)` | `y` か `n`。**Confirm 設定時は `yes` + Enter が必要**(下記) |
| 選択プロンプト | `What do you want to use? [a-f or ?*]` / `In what direction?` | 該当文字を送る。やめるなら Escape |
| メニュー表示中 | 最終行が `(end)` または `(1 of 2)` | Escape で閉じる。複数ページなら `>` で次、`<` で前 |

`assets/nethackrc` は `paranoid_confirmation` に `Confirm` を入れているので、
確認プロンプトの一部は **`y` ではなく `yes` を打って Enter** しないと通らない。
`[yn]` と出ていても `Do you want to ... ? [yes/no]` の形なら文字列入力である。画面の表記に従うこと。

メニューは `!menu_overlay` により**画面全体を置き換える**。
つまり **メニュー表示中はステータス行が見えず HP を確認できない**。
インベントリ等を開いたら、判断の前に Escape で閉じて通常画面に戻ること。

## 移動

```
y k u
 \|/     小文字 = 1マス
h- . -l  大文字 (YUHJKLBN) = その方向へ止まるまで走る
 /|\
b j n
```

`number_pad:0` 設定なので数字キーは移動にならない(数字は回数プレフィックス)。

### 移動プレフィックス

これを使わないと事故る場面がある。

| プレフィックス | 意味 |
|---|---|
| `m` + 方向 | 拾わない・戦わないで移動。**罠や水際を意図的に通るときにも必要** |
| `F` + 方向 | 強制攻撃。見えない相手(`I` マーク等)を殴るとき |
| `g` + 方向 | 何か面白いものが見つかるまで進む |
| `G` + 方向 | `g` と同じだが通路の分岐では止まらない |
| `_` | **travel。目的地をカーソルで指定して最短経路で移動する** |
| `Ctrl+_` | 直前の travel 目的地へ再度移動(`#retravel`) |

**`_`(travel)は自動プレイで最も有用なコマンド。** 1手ずつ `hjkl` を送るより
送信回数が桁で減り、途中に `--More--` が挟まる事故も減る。
`_` のあとカーソル移動キーで目標を選び `.` か `,` で確定する。
`m_` とすると視界内の「行き先候補メニュー」が出る。

`autodescribe` + `whatis_coord:m` を設定してあるので、カーソル移動中に
`<x,y>` 付きで足元の説明が出る。目的地を間違えにくい。

`_` で目標を選んだとき、上部に `(no travel path)` と出たら経路が無い。

### 回数指定

コマンドの前に数字を置くと繰り返す。`10s` で10回サーチ、`20.` で20ターン待機。
`number_pad:0` なので `n` プレフィックスは不要。**キャンセルは Escape。**

## 1文字コマンド(5.0.0 の既定バインド)

### 情報を得る(ターンを消費しない。安全)

| キー | 動作 |
|---|---|
| `i` | インベントリ |
| `I` | 種類を絞ってインベントリ。**`IB`/`IU`/`IC`/`IX` = 祝福/無呪/呪い/BUC不明 の一覧**、`I$` 所持金、`Iu` 未払い |
| `:` | 足元を見る |
| `;` | farlook。画面上の1文字が何かを調べる(**ペットか敵かの判別はこれ**) |
| `/` | whatis。文字や単語から説明を引く |
| `&` | そのキーが何のコマンドか教える |
| `^` | 既知の罠の種類を確認(`#showtrap`) |
| `\` | 識別済みアイテム一覧(`#known`) |
| `` ` `` | 1クラスだけの識別済み一覧 |
| `*` | 装備中のもの全部(`)` 武器 / `[` 防具 / `=` 指輪 / `"` アミュレット / `(` 道具 に分解も可) |
| `$` | 所持金 |
| `+` | 習得している呪文一覧 |
| `^X` | キャラクター情報の詳細 |
| `^O` | ダンジョン概観(`#overview`)。**訪れた階の祭壇・店・階段などが一覧できる** |
| `v` | 重要イベントの年代記(`#chronicle`)。**再開時の状況把握に効く** |
| `V` | バージョン表示 |
| `^P` | 直前のメッセージを再表示。連打で更に過去へ |
| `^R` | 画面再描画。**表示が壊れたと思ったらまずこれ** |
| `?` | ヘルプメニュー |

`;` と `/` の使い分け: `;` は**画面上の位置**を指定、`/` は**文字そのもの**を指定。
`;` はカーソルを動かして `.` か `,` で確定する。

### 行動する(ターンを消費する)

| キー | 動作 |
|---|---|
| `,` | 拾う。`m,` でメニュー強制 |
| `d` / `D` | 1つ捨てる / 種類を指定して捨てる(`DB`/`DU`/`DC`/`DX`/`Da`/`Dm` などのフィルタ) |
| `w` | 武器を装備(`w-` で素手) |
| `W` / `T` | 防具を着る / 脱ぐ |
| `A` | **装備を一括で外す**(`#takeoffall`) |
| `P` / `R` | 装飾品(指輪・アミュレット・目隠し)を着ける / 外す |
| `x` | 主武器と持ち替え用武器を交換 |
| `X` | 二刀流の切り替え(`#twoweapon`) |
| `q` | 飲む。泉やシンクの上だとそちらを勧められる。**`mq` で飲泉を飛ばして持ち物から選ぶ** |
| `r` | 巻物・魔法書を読む |
| `a` | 道具を使う(apply)。**杖に使うと杖を折る。確認あり** |
| `z` / `Z` | 杖を振る / 呪文を唱える(`z.` `Z.` で自分に) |
| `t` | 投げる |
| `f` | quiver から撃つ。`Q` で quiver を選んでおく |
| `Q` | quiver を選ぶ |
| `E` | 刻む(`E-` で指で床に書く) |
| `e` | 食べる。**`me` で床のものを無視して持ち物から選ぶ** |
| `s` | サーチ(隠し扉・罠)。1ターン待機も兼ねる |
| `.` | 1ターン待つ |
| `o` / `c` | ドアを開ける / 閉める |
| `^D` | 蹴る |
| `<` / `>` | 上る / 下りる |
| `p` | 買い物の支払い |
| `C` | 名前を付ける(`#call` / `#name` と同じ) |
| `@` | autopickup の切り替え |
| `^A` | 直前のコマンドを繰り返す |
| `S` | セーブして終了 |

## 拡張コマンド(`#`)

**送り方が重要。`#` とコマンド名を送っただけでは実行されない。最後に Enter が要る。**

```bash
scripts/cmux_nethack.sh ext pray      # 推奨: '#pray' + Enter をまとめて送る
```

手で組むなら:

```bash
scripts/cmux_nethack.sh keys "#pray"
scripts/cmux_nethack.sh key enter
```

**meta キー(`M-p` 等)は使わないこと。** cmux から meta を送るのは
Escape+文字の合成に頼ることになり、`assets/nethackrc` ではその挙動(`altmeta`)を
安全のため無効化してある。拡張コマンドは必ずフルネーム + Enter で送る。

### 通常プレイで使う拡張コマンド

| コマンド | 用途 | 既定キー |
|---|---|---|

| `#offer` | 祭壇で生贄 | `M-o` |

| `#force` | 鍵のかかった箱をこじ開ける(武器が要る) | `M-f` |
| `#untrap` | 罠・扉・箱の罠を外す。罠にかかった味方の救出にも | `M-u` |
| `#loot` | 足元の箱・袋を開ける。騎乗中の鞍の取り外しにも | `M-l` |
| `#tip` | 容器をひっくり返して中身を全部出す | `M-T` |
| `#dip` | 何かに浸す(泉・聖水など) | `M-d` |
| `#invoke` | アーティファクトの能力を発動 | `M-i` |
| `#rub` | ランプや石をこする | `M-r` |
| `#wipe` | 顔を拭う(**目潰しを食らったら最優先**) | `M-w` |
| `#sit` | 座る(玉座・産卵など) | `M-s` |
| `#turn` | アンデッド退散(Priest/Knight など) | `M-t` |
| `#jump` | 跳ぶ(Knight、跳躍靴など) | `M-j` |
| `#ride` | 騎乗する/降りる | `M-R` |
| `#monster` | 変身中に固有能力を使う | `M-m` |
| `#adjust` | 持ち物の文字を並べ替える / スタックを分割する | `M-a` |

| `#herecmdmenu` / `#therecmdmenu` | 足元 / 隣接マスに対して可能な行動をメニューで出す | なし |
| `#conduct` | 守っている縛りプレイの一覧 | `M-C` |
| `#vanquished` | 倒したモンスターの集計 | `M-V` |
| `#quit` | ゲームを捨てて終了。**使わない**(中断は `S`) | なし |

`#terrain` と `#lookaround` は 3.6 世代の攻略記事にほぼ出てこないが、
**画面を読んで判断する自動プレイとは相性が良い**。マップにモンスターやアイテムが
重なって地形が見えないとき、`#terrain` で下地を確認できる。

`#overview` / `#annotate` / `#chronicle` は**ゲームがセーブファイルに持っている進捗記録**。
外部ログ(`cmux_nethack.sh note`)と違ってセーブと一緒に残るので、
「Minetown はどこだったか」「祭壇のある階はどこか」は外部ログより先にこちらを見る。

## 3.6 からの変更(間違えやすい)

| 項目 | 3.6 | 5.0.0 |
|---|---|---|
| `v` | バージョン表示 | **`#chronicle`(イベント一覧)** |
| `V` | — | バージョン表示 |
| `X` | explore モードへ切替 | **二刀流の切替**(explore は `#exploremode`) |
| `M` + 方向 | 移動プレフィックス | **廃止**。`m` と `G`/`g` を組み合わせる |
| `number_pad` | 真偽値 | **0〜4 の値**。`!number_pad` は設定エラー |
| DECgraphics / IBMgraphics | 真偽オプション | **`symset` の値** |
| 起動時 | — | **チュートリアルの可否を聞かれる**(`!tutorial` で抑止) |

## 送信の実務

- **1回に送るのは1〜2アクション分まで。** 途中に `--More--` やプロンプトが挟まると
  残りが全部誤入力になる。長距離の移動は連打ではなく `_`(travel)を使う。
- **Escape は `key escape` で送る。** テキストとしては送れない。
- **Space が「何も起きない場所」で送られると `Unknown command ' '.` が出る。**
  これが出ていたら、`--More--` が無いのに Space を送ったということ。状態把握が
  ずれている合図なので、`^R` で再描画してから読み直す。
- `\`(識別済み一覧)は `cmux send -- '\'` で送れるが、直後に `n`/`r`/`t` が続く
  文字列はエスケープと誤解釈されるので1文字ずつ送る。
